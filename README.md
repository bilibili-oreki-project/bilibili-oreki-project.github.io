# OREKI paper project page

A buildless, responsive page for GitHub Pages.

## Preview
Open index.html, or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

## GitHub Pages
1. Upload the contents of this folder to your repository root.
2. In Settings → Pages choose Deploy from a branch, main, / (root).
3. Use the URL displayed by GitHub Pages.

For a project repository the URL is https://USERNAME.github.io/REPOSITORY/. For a personal homepage the repository name must be USERNAME.github.io.

## Edit
Text, styling, and interactions are in index.html. Original figures are in static/images; paper.pdf and slides.pdf are bundled. No external font or JavaScript dependency is required.

Author names follow the paper. No unverified conference, equal-contribution designation, code URL, or dataset URL has been added. BibTeX is a manuscript entry; replace it with official metadata before public release. Case 1 and Case 2 preserve the presentation order and original embedded images.
